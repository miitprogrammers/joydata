# Materi Bunpou

Fitur dashboard sensei untuk menjelaskan pola tata bahasa di kelas: **cari pola → daftar → klik → halaman presentasi**.
Status (2026-11-21): halaman dan 6 materi pilot sudah dibuat, menunggu tinjauan sensei. Lihat [progres.md](progres.md).

| File | Isi |
|---|---|
| [progres.md](progres.md) | Status per fase, hasil tes dan cek visual, hal yang perlu dicek |
| [spek-kode.md](spek-kode.md) | Spesifikasi kode yang dipakai agen: kontrak data, validator, API, layar |
| [katalog.md](katalog.md) | Laporan katalog 163 pola (per bab, per kategori modul, keputusan yang perlu dicek) |
| [plan.md](plan.md) | Tujuan, fase F0–F7, urutan produksi isi, file yang disentuh, definition of done, risiko, **pertanyaan Q1–Q7** |
| [design.md](design.md) | Alur, mockup layout (ASCII) layar cari dan presentasi, urutan slide, kontrol, model data, arsitektur, aturan penulisan isi |
| [mockup.html](mockup.html) | Mockup yang bisa diklik (buka di browser). Coba ketik `kalau`, `tara`, `bab 25`, `#11`, lalu buka ～たら |
| [contoh-materi-tara.md](contoh-materi-tara.md) | Isi lengkap satu materi (～たら) sebagai pilot gaya penjelasan, contoh kasus, dan padanan bahasa Indonesia |
